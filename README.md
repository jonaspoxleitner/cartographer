# cartographer

A Java 21 project built with Maven.

## Requirements

- Java 21+
- Maven 3.9+

## Build

```bash
mvn package
```

## Run

```bash
java -jar target/cartographer-1.0-SNAPSHOT.jar
```

## Test

```bash
mvn test
```

## Project layout

```
src/main/java/com/cartographer/   # application code
src/test/java/com/cartographer/   # JUnit 5 tests
```
