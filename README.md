# cartographer

A Java 21 project built with Maven.

## Requirements

- Java 21+
- Maven 3.9+

## Build

```bash
make package   # or: mvn package
```

## Run

```bash
make run       # builds the package and runs the jar
```

## Clean

```bash
make clean     # or: mvn clean
```

## Test

```bash
mvn test
```

## Project layout

```
src/main/java/com/cartographer/   # application code
src/test/java/com/cartographer/   # JUnit 5 tests
```
